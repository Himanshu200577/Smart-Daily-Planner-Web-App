# Smart-Daily-Planner-Web-App

 Built a responsive daily planning web application for organizing tasks, priorities, schedules, and daily productivity goals through an interactive dashboard.  

## 🔥 Features
- Add, delete, and complete tasks
- Due date selection
- Overdue task highlighting
- Dark / Light mode
- LocalStorage data persistence
- Fully offline

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 🧠 Concepts Used
- DOM Manipulation
- LocalStorage
- Event Handling
- Responsive UI Design
